# 🏥 Ruhina Hospital Management System

A web-based **Hospital Management System** developed as a DBMS mini project using PHP, MySQL, HTML, and CSS.

The system provides an admin interface to manage patients, doctors, appointments, prescriptions, medicines, and billing information in an organized database-driven application.

---

## 📌 About the Project

The **Ruhina Hospital Management System** is designed to simplify and organize common hospital management activities.

The system provides a centralized platform where an administrator can manage:

- Patient records
- Doctor information
- Hospital departments
- Appointments
- Prescriptions
- Medicines and stock
- Billing and payment status

The project demonstrates the practical implementation of **Database Management System concepts** using a web-based application.

---

## ✨ Features

### 🔐 Admin Authentication
- Secure admin login
- Password hashing
- Session-based authentication
- Logout functionality
- CSRF protection

### 👤 Patient Management
- Add patient records
- View patient information
- Update patient details
- Delete patient records

### 👨‍⚕️ Doctor Management
- Add doctors
- Store specialization and contact information
- Associate doctors with departments
- Manage doctor records

### 📅 Appointment Management
- Schedule appointments
- Associate patients with doctors
- Store appointment date and time
- Record appointment reason
- Manage appointment status

### 💊 Prescription Management
- Create prescriptions
- Store diagnosis information
- Associate medicines with prescriptions
- Store dosage and duration

### 💉 Medicine Management
- Add medicines
- Maintain medicine prices
- Track medicine stock
- Manage medicine records

### 💰 Billing Management
- Generate billing records
- Store bill amounts
- Track payment status
- Associate bills with appointments
